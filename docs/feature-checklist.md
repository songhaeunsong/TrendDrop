# TrendDrop 화면별 기능 체크리스트

> 현재 코드 기준으로 각 페이지가 UI 섹션별로 어떤 기능을 갖고 있는지, 그리고 각 기능이
> 실제로 얼마나 완성되어 있는지 정리합니다. `/collection-log`, `/collection-log-v-he`는
> 내부 개발용 로그 화면이라 이 체크리스트에서는 제외했습니다.

**범례**

- ✅ 완성 — 프론트·백엔드 모두 실제로 동작
- 🟡 프론트만 완성 — UI/인터랙션은 다 되어 있지만 mock 데이터거나 백엔드 미연동
- ❌ 구현예정인 기능

---

## 1. `/` 홈 — 실시간 랭킹

### 1.1 랭킹 리스트

- 🟡 실시간/24시간 탭 전환
- 🟡 카테고리 필터 탭
- 🟡 LIVE 토글(8초 간격 자동 갱신 on/off)
- 🟡 타임머신 스크러버(과거 12개 시점 이동)
- 🟡 타임랩스 재생/일시정지(자동 진행 후 최신 시점에서 정지)
- 🟡 실시간 하이라이트 티커(신규/급상승 키워드 배너, 클릭 시 해당 행으로 스크롤)
- 🟡 순위 변동 FLIP 애니메이션 + 상승/하락/신규 플래시 하이라이트
- 🟡 미니 스파크라인(막대형 마이크로 차트)
- 🟡 등락 배지(▲상승/▼하락/NEW/-)
- 🟡 요약 통계(추적 키워드 수·신규 진입·최고 상승률) + 롤링 숫자 애니메이션
- 🟡 풀투리프레시(터치 기기, 실시간 모드 한정)
- 🟡 커맨드 팔레트에서 넘어온 카테고리 필터 자동 적용
- 🟡 랭킹 행 클릭 → 키워드별 상세 페이지 이동

### 1.2 수집 컨트롤

- ✅ "최신 트렌드 수집" 버튼(실제 백엔드 파이프라인 호출·DB 저장)
- ✅ 수집 결과/에러 메시지 표시
- ✅ 수집 기록 페이지 링크
- ✅ 수집 완료 후 랭킹 리스트에 결과 자동 반영

### 1.3 워치리스트 패널

- 🟡 키워드/메타 설명/점수 카드 리스트 표시
- 🟡 키워드 저장/삭제

---

## 2. `/explore` 탐색

### 2.1 카테고리 × 시간 히트맵

- 🟡 셀 진하기로 heat(0~100) 표시
- 🟡 열 헤더에 시점 라벨, 최신 열 강조
- 🟡 행(카테고리) 클릭 → 필터 적용 후 홈으로 이동
- 🟡 실제 DB 시계열 기반 heat 계산

### 2.2 키워드 A/B 비교

- 🟡 키워드 선택 드롭다운 2개(최신 상위 20개 중 선택)
- 🟡 SVG 순위 궤적 차트(이탈 구간은 선이 끊김)
- 🟡 진입 지점/현재 지점 마커 표시
- 🟡 범례 + 등락 배지
- 🟡 Y축 가이드라인(1위/10위/20위), X축 시간 눈금
- 🟡 실제 DB 시계열 기반 궤적

---

## 3. `/trend` 트렌드 상세

- 🟡 상단바(뒤로가기, 순위 배지, 카테고리 태그)
- 🟡 히어로 영역(카테고리, 키워드명, 분석 시점)
- 🟡 핵심 지표 4종(검색 상승률·확산 속도·트렌드 점수·감지 시점)
- 🟡 상승 추이 스파크라인(요일 라벨 포함 SVG 차트)
- 🟡 AI 요약 · 왜 뜨나(요약 + 출처별 근거 리스트)
- 🟡 관련 콘텐츠 카드(플랫폼 아이콘, 제목, 참여 지표, 콘텐츠 종류)
- 🟡 연관 키워드 칩
- 🟡 감지 채널 목록(라이브 표시 점)
- 🟡 라우트 파라미터화(`/trend/[slug]`)
- 🟡 실제 키워드별 데이터 조회

- ✅ 저장된 트렌드 조회 버튼 + 결과 카드 그리드 렌더링
- ✅ 원시 응답 뷰어(JSON pretty-print, 요청 상태 칩 idle/loading/success/error)
- ✅ 접근 제어

## 요약: 우선 처리하면 좋은 항목

1. **랭킹 행 → 상세 페이지 라우팅 버그** (1.1 마지막 항목) — 클릭 경험이 근본적으로 깨져 있어 가장 먼저 고칠 가치가 있음
2. **수집 후 화면 미반영** (1.2 마지막 항목) — 버튼은 동작하는데 결과가 안 보여 사용자가 오작동으로 오인하기 쉬움
3. **`/trend` 라우트 파라미터화** (3장 마지막 두 항목) — 1번 항목의 전제 조건
4. **`/api-lab` 접근 제어** (4장 마지막 항목) — 배포 전 반드시 필요한 보안 항목
